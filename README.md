# สมุดเงินใต้ร่มไม้

Thai offline PWA. Personal financial records stay in each user's IndexedDB. No account, cloud sync, external scripts or financial-data upload.

## Enable free hosting
Settings → Pages → Deploy from a branch → main → /(root) → Save.
After GitHub confirms deployment, open the published HTTPS URL in Safari → Share → Add to Home Screen. Wait for the offline-ready indicator before disconnecting.

Back up JSON regularly. Clearing website data can erase records. JSON backups are not encrypted.
